The Solution

The PitPulse Framework

01 ACOUSTIC CAPTURE
Ingests raw driver team radio feeds, dynamically downmixing to 16kHz mono audio. Runs transcription via local ML speech models.
02 STATE CLASSIFICATION
Fuses text sentiment analysis and vocal emotion models. Applies formulas combining volume and silence features to label driver state.
03 TELEMETRY CORRELATION
Correlates stress triggers to lap telemetry, calculating baselines and deltas to provide automated engineering pit strategy suggestions.
Tech Approach

Multimodal Sentiment Fusion

ML MODEL ARCHITECTURE
ASR Engine openai/whisper-tiny fine-tuned on custom F1 driver transcripts.
Text Emotion distilroberta-base mapping anger, fear, disgust, and sadness.
Vocal Emotion (SER) wav2vec2-base-superb-er reading raw mono waveform signals.
Acoustic Stats Extracts speech energy (RMS) and silence ratio to evaluate fatigue.
FUSION & STATE MATRICES
Final Stress = 45% Voice + 30% Text + 15% Urgency + 10% Fatigue
Low Stress, Low Fatigue CALM
Combined Stress Score > 50% STRESSED
Speech Pauses & Fatigue > 50% TIRED
Tech Approach

Telemetry & Correlation Engine

01 / CSV INGESTION

Ingests telemetry data using Pandas. Deduplicates existing records in the SQLite database and calculates fallback sector splits (Lap Time / 3) if telemetry sector fields are missing.

02 / CALM BASELINE

Detects the first transition lap where driver status shifts from Calm to Stressed or Tired. Computes an anchor baseline by averaging the last 3 Calm laps preceding this trigger.

03 / CORRELATION

Calculates pace loss delta: (Lap Time - Baseline) / Baseline * 100. Pinpoints exactly which sector is degrading and outputs plain-language tactical directives.
